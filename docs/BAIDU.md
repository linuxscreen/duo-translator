# 百度翻译接入说明

Duo Translator 使用百度翻译开放平台的「通用文本翻译 API」。接口说明见[百度官方文档](https://fanyi-api.baidu.com/doc/21)，账户参数以自己的控制台为准。

## 账号与配置

在百度翻译开放平台开通通用文本翻译服务，取得 APPID 和密钥。百度智能云 AK/SK、领域翻译和大模型翻译属于其他接口，不能直接填入这里。

打开扩展设置 → 翻译服务 → 百度翻译的编辑窗口：

| 字段 | 填写内容 |
| --- | --- |
| APPID | 控制台显示的 APPID，按文本填写 |
| 密钥 | 与该 APPID 对应的密钥 |
| QPS | 本扩展的请求速率上限，整数 1—100，默认 1 |

可用尚未保存的参数点击「测试」。成功后保存，开启服务，再到网页翻译等入口选择百度。导入原版配置后也应检查服务开关和当前选用的翻译服务。

## 翻译范围

百度接入覆盖网页、划词、输入框、普通翻译工作台和字幕翻译。原版的词典、朗读、AI 纠错/润色、AI 字幕分句和其他服务仍按各自设置工作。

当前适配的目标语言：简体中文、繁体中文、英语、日语、韩语、法语、西班牙语、泰语、阿拉伯语、俄语、葡萄牙语、德语、意大利语、希腊语、荷兰语、波兰语、保加利亚语、爱沙尼亚语、丹麦语、芬兰语、捷克语、罗马尼亚语、斯洛文尼亚语、瑞典语、匈牙利语、越南语。适配器另有粤语代码映射，原版设置没有该选项。

其他语言可能仍出现在原版共用的语言列表中；选用百度且未适配时，会返回明确错误。源语言由百度自动识别；接口的 `from` 是整批请求的语种，不能当作每一段的独立检测结果。整页语种检测失败时会回退 Microsoft；段落排除语种检测仍使用 Microsoft。

## 排队、格式与费用

- 本扩展后台共用一个串行队列，按 QPS 控制百度请求间隔。此限制只覆盖本扩展，账户在其他客户端的调用不受它控制。
- 长文本按 UTF-8 字节长度拆分，每批保持在 5800 字节以内。单次网络请求超过 25 秒超时；普通百度翻译调用等待上限为 120 秒，不含连接测试和独立语种检测。排队过长时可降低翻译范围或适当提高账户允许的 QPS。
- 网页中的链接、强调等行内元素以映射标签随句子发送。返回标签不完整或次序变化时，改为翻译各个文本片段，再放回原标签；这会增加请求次数，也可能影响跨片段语境。
- 点击测试、百度源语种检测样本和必要的标签回退都会请求 API。检测样本最多 800 个 UTF-8 字节。额度、计费和频控以自己的账户为准。
- 停止翻译会取消可取消翻译通道中仍在排队和正在等待的请求；独立语种检测尚未接入取消信号。已被百度接收处理的内容，是否计费由服务端决定。

## 常见错误

| 提示/代码 | 检查事项 |
| --- | --- |
| 缺少 APPID 或密钥 | 先保存完整配置，再开启服务 |
| 52003 / 54001 | APPID 是否有效、密钥是否配对、是否有多余空格 |
| 54003 | QPS 是否超出账户额度，是否有其他程序共用账号 |
| 54004 | 账户可用额度和余额 |
| 58000 | 百度控制台的 IP 限制与当前出口 IP |
| 58001 | 是否选择当前适配的目标语言 |
| 58002 / 90107 | 通用翻译服务是否开启，认证是否通过并生效 |

## 凭据与公开代码

百度请求通过 HTTPS POST 发送，签名在扩展后台计算。请求包含 APPID、待翻译内容、随机盐和签名，原始密钥不作为请求参数发送。网页内容脚本通过消息请求后台翻译，不持有百度 HTTP 客户端。

APPID 和密钥保存在本机扩展的 `storage.local`；这是明文配置，具有本机访问权限的软件仍可能读取。密钥输入框使用密码类型遮挡显示。

百度密钥默认从配置备份与同步快照中排除。用户明确勾选「包含 API 密钥」时，密钥会进入对应数据；导入已脱敏的配置会保留本机已有密钥。APPID 不作为秘密字段排除，因此分享自己导出的配置前仍应检查内容。

百度凭据由用户在设置页填写，不应硬编码到源码或随扩展分发。个人 `.env`、包含凭据的配置导出和浏览器配置目录不应提交到仓库。
